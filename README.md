# Word Scanner (Frontend mock)

This is a frontend-only Flutter app that demonstrates a polished UI for uploading or taking a photo, "scanning" the image (mocked), and showing sample word detection results (Genuine / Fake / Unknown).

Run:

```bash
flutter pub get
flutter run
```

Notes:
- No backend, OCR, or AI is included — results are mocked.
- Uses Material 3 and `image_picker` for image selection.
